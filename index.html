Monitoramento de Qualidade da Água em Corpo Hídrico Litorâneo

Análise de dados do monitoramento de qualidade da água de um corpo hídrico litorâneo, em 10 pontos amostrais

Tecnologias: Excel Power BI DAX Power Query / ETL

As principais medidas em DAX usadas no Power BI são listadas em seguida:

Limite Máximo PARA CADA PARÂMETRO 
LimiteMáximo = 
VAR Param = SELECTEDVALUE('DADOS_SUP'[Parâmetro])
RETURN
    LOOKUPVALUE(
        'PARAMETROS'[Limite máximo],
        'PARAMETROS'[Parâmetro], Param
    )
QUANTIDADE DE medições (AMOSTRAS SUPERFICIAIS) 
Qtd. medições SUP = countrows(DADOS_SUP)
QUANTIDADE DE não conformidades REGISTRADAS NAS AMOSTRAS SUPERFICIAIS 
Qtd. não conformidades SUP = 
CALCULATE(
    [Qtd. medições SUP],
    DADOS_SUP[Conformidade] = "Não conforme")
PERCENTUAL DE Não conformidade NAS AMOSTRAS SUPERFICIAIS 
% Não conformidade SUP = 
DIVIDE(
    [Qtd. não conformidades SUP],
    [Qtd. medições SUP])

O projeto é baseado em dados fictícios organizados no mesmo modelo de planilha Excel que estruturei durante minha mais recente experiência profissional. Trata-se de um monitoramento de qualidade da água em um corpo hídrico litorâneo, em 10 pontos amostrais, durante 18 campanhas mensais de um programa ambiental.

Os valores máximos permitidos (VMP) usados como base de comparação são os determinados na Resolução CONAMA Nº 357/05, importante legislação usada no contexto ambiental de enquadramento de corpos hídricos.

A análise teve como foco verificar as alterações dos principais parâmetros de qualidade da água ao longo do monitoramento, a fim de identificar possíveis impactos ambientais no corpo hídrico em questão. Foi analisada também a possibilidade de variação sazonal, de acordo com a definição de estações meteorológicas.

O principal desafio para esse projeto foi a estruturação dos dados oriundos do laboratório responsável pela análise, para unificar e padronizar as colunas com os dados de todo o período monitorado. A mescla e padronização dos dados foi realizada no Excel.

Foram elaborados um formato de planilha e um dashboard únicos prontos para receber novos dados a cada mês de monitoramento, facilitando a atualização e o acompanhamento das variações da qualidade da água no corpo hídrico em questão.

A organização do dashboard e a estruturação da planilha de dados acelerou o processo de atualização de dados a cada mês de realização de campanhas amostrais. Os gráficos e as segmentações utilizadas no dashboard contribuíram para melhorar a visualização e a interpretação do usuário, leitor do relatório, e o entendimento das alterações ao longo do tempo no corpo hídrico.
